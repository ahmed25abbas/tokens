Auto Lobby (serverless P2P)

Trystero discovers peers using public infrastructure (no server you run). If torrent trackers are blocked, it falls back to Nostr relays.

Important: STUN rotation improves reliability a bit, but won’t bypass hard ISP/firewall blocking. If your ISP blocks WebRTC paths, only a TURN relay reliably fixes it (requires credentials).
